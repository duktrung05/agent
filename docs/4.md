# Bài 2 — Tạo hàm tìm kiếm PubMed

**Mục tiêu:** Gọi API thật, nhận danh sách PMID. Chạy trực tiếp trước khi đưa hàm cho model dùng như tool.

## Chạy một lần

Tại thư mục gốc repo:

```bash
python3 lessons/02_search_pubmed.py --query 'Alzheimer AND sleep' --limit 3
```

Không cần cài package ngoài hoặc API key. Lệnh này gọi PubMed, không gọi model trả phí.

## Đọc kết quả

| Trường | Ý nghĩa |
|---|---|
| `query` | Truy vấn bạn gửi |
| `total_matches` | Tổng số bản ghi khớp tìm kiếm, chưa có nghĩa tất cả phù hợp nghiên cứu |
| `returned` | Số PMID được trả trong lượt này, tối đa theo `--limit` |
| `pmids` | Định danh bản ghi; chưa phải tiêu đề hoặc abstract |
| `query_translation` | Cách PubMed diễn giải truy vấn, khi API cung cấp |
| `query_errors`, `query_warnings` | Vấn đề/cảnh báo truy vấn cần đọc trước khi diễn giải kết quả |
| `fetched_at` | Thời điểm truy xuất, UTC |

## Hiểu phần cốt lõi

```text
query → urlencode → GET ESearch → JSON → idlist → PMID
```

Trong [script](../lessons/02_search_pubmed.py), đọc `search_pubmed`:

1. Tạo tham số `db`, `term`, `retmax`, `retmode`.
2. Gửi GET với timeout 30 giây mỗi lần; thử lại tối đa một lần sau 1 giây nếu lỗi mạng,
   HTTP 429/5xx tạm thời hoặc response không phải JSON. Lỗi định dạng kèm HTTP,
   Content-Type và đoạn đầu response để điều tra; nếu vẫn lỗi thì dừng.
   Nếu nhận diện trang chặn NCBI, dừng ngay và báo đúng lỗi nguồn, không tự retry trang chặn.
3. Kiểm tra response rồi lấy `esearchresult.idlist` và `count`.

Query là tham số truyền vào, không có nhánh Python riêng cho Alzheimer.
Thử đổi sang `--query 'COPD AND pulmonary rehabilitation'` để kiểm tra cùng hàm.

**Đạt khi:** Nhận được PMID, giải thích được `total_matches` khác `returned` thế nào.
Kết quả rỗng khác lỗi mạng; nếu có `query_errors`, phải kiểm tra truy vấn trước.

Đây mới là hàm có thể dùng làm tool. Lần sau mới thêm schema và để model yêu cầu gọi hàm.
Trước phần tổng hợp bài báo sẽ cần bước lấy metadata/abstract riêng.

Nguồn: [Hướng dẫn E-utilities của NLM](https://dataguide.nlm.nih.gov/eutilities/utilities.html).
