# Bài 4 — Lấy nội dung bản ghi từ PMID

**Mục tiêu:** Nhận tiêu đề và abstract thật, thay vì chỉ có mã bài báo.

```text
search_pubmed(query) → PMID → fetch_pubmed_records(pmids) → metadata + abstract
```

## Chạy một bài trước

Tại dấu `$` của Bash, không nhập trong `Bạn>` hoặc `>>>`:

```bash
python3 lessons/04_fetch_pubmed.py --pmids 39137870
```

Có thể thay bằng PMID bạn nhận ở bước tìm kiếm. Hàm nhận tối đa 3 PMID mỗi lượt.
Không cần Ollama, API key hoặc package Python ngoài; cần Internet để đọc PubMed.

## Đọc kết quả

| Trường | Ý nghĩa |
|---|---|
| `records[].pmid`, `url` | Định danh và trang nguồn |
| `title` | Tiêu đề trong bản ghi |
| `publication_year`, `doi` | Metadata nếu bản ghi có; thiếu thì `null` |
| `abstract` | Nội dung abstract; giữ tiêu đề các phần nếu có |
| `content_scope` | `metadata_and_abstract` hoặc `metadata_only` |
| `missing_pmids` | Mã được yêu cầu nhưng không có bản ghi trả về |
| `fetched_at` | Thời điểm truy xuất, UTC |

## Hiểu ba hàm

- `fetch_pubmed_records()`: tạo URL, gọi EFetch, nhận XML.
- `parse_records()`: biến cấu trúc XML thành dict có trường rõ ràng.
- `element_text()`: giữ chữ trong các thẻ con; đọc `.text` đơn thuần có thể làm mất nội dung.

EFetch ở bài này dùng XML, khác ESearch JSON của bài tìm kiếm.
Không có abstract là dữ liệu thiếu, không được tự sinh abstract thay thế.
Abstract không đồng nghĩa full-text. Chỉ ghi năm từ trường Year đã đọc; chưa chuẩn hóa đầy đủ các kiểu ngày.
Nếu NCBI trả trang chặn HTML dù HTTP 200, hàm sẽ báo lỗi định dạng/nguồn và dừng,
không coi trang đó là bài báo hoặc kết quả thiếu abstract.

**Đạt khi:** Mở `url` để đối chiếu tiêu đề và abstract với JSON.

**Đã kiểm tra:** Request thật cho PMID `39137870` trả được tiêu đề và abstract.
Bảy kiểm thử parser/validation đã đạt, gồm nội dung có thẻ con, abstract chia phần,
thiếu abstract, thiếu PMID, response lỗi, PMID ngoài yêu cầu và bản ghi sách.

Bài này chỉ chạy hàm trực tiếp. Bước sau mới công bố thêm tool `fetch_pubmed_records`
để model có thể tìm PMID rồi lấy nội dung qua hai lần gọi tool phụ thuộc nhau.

Nguồn: [EFetch của NLM](https://dataguide.nlm.nih.gov/eutilities/utilities.html#efetch),
[cấu trúc AbstractText](https://dtd.nlm.nih.gov/ncbi/pubmed/doc/out/250101/el-AbstractText.html).
